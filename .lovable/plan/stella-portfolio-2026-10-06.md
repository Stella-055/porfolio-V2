# Stella Portfolio

## Build
- Replace the blank page with a dark-first, single-page portfolio using an editorial, asymmetric composition and one restrained signal-green accent.
- Create the sticky navigation, interactive hero system map, About profile, five-project showcase, project detail overlays, filterable skill matrix, experience timeline, four-part specialization view, personal highlights, contact area, and footer.
- Keep projects, skills, experience, and highlights in editable data structures and split the interface into focused reusable components.

## Interaction and imagery
- Add subtle cursor response, scroll-linked navigation changes, restrained reveal effects, animated system-flow diagrams, a mobile menu, and keyboard-accessible dialogs.
- Create original abstract technical artwork for the project showcase. Use intentional placeholders for Stella’s graduation, hackathon, and certificate photos until the real images are supplied.
- Respect reduced-motion preferences and provide intentional mobile layouts rather than simply stacking desktop sections.

## Technical details
- Use React, TypeScript, Tailwind CSS, and Motion for React; add only the animation dependency requested in the brief.
- Define the full dark visual system as semantic tokens, load distinctive display/body/mono fonts through the document head, and add complete page metadata.
- Verify the finished page at desktop and mobile sizes, including navigation, filters, project overlays, highlight lightbox, links, and visible overflow.
